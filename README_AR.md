# apkengine v0.1 — محرك بناء APK (المرحلة 1: تجربة خاصة على GitHub)

الوظيفة الوحيدة: **ZIP لمشروع Android أصلي ← بناء Gradle ← APK (أو سبب الفشل)**.

## محتوى الحزمة (5 ملفات في مستوى واحد)
`apkengine.py` · `test_apkengine.py` · `apk-engine.yml` · `THIRD_PARTY_NOTICES.md` (لا تحذفه: شرط ترخيص MIT) · `README_AR.md`

## الرفع (من الجوال)
1. **فك الضغط** عن الحزمة بتطبيق الملفات (Files) أو ZArchiver. GitHub لا يفك ملفات ZIP عند الرفع.
2. GitHub ← **New repository** ← **Private** ← Create.
3. **Add file ← Upload files**: حدّد الملفات الخمسة معاً وارفعها، ثم Commit.
4. افتح `apk-engine.yml` في المستودع ← أيقونة القلم (Edit) ← في خانة اسم الملف في الأعلى اكتب بدلاً منه:
   `.github/workflows/apk-engine.yml` ← Commit. (إن لم يقبل: أنشئ ملفاً جديداً بهذا الاسم والصق المحتوى.)

## التشغيل
- **الاختبارات الذاتية:** تبويب Actions ← apk-engine ← Run workflow ← اترك الخانة **فارغة**. المتوقع: أخضر (24 اختباراً).
- **بناء مشروع:** ارفع ZIP مشروعك إلى جذر المستودع (Add file ← Upload files)، ثم Run workflow واكتب اسمه (مثال `myapp.zip`).
  - قبل الضغط احذف `build/` و`.gradle/` و`.idea/`، ولا تضع مفاتيح (`*.jks`) ولا `local.properties`. حد الرفع من المتصفح نحو 25 MB.
- النتيجة: ملخص بالعربية أعلى صفحة التشغيل + Artifact باسم `apk-result` فيه `apks/` و`result.json` و`build.log`.

## ماذا ترسل لي لكل مشروع؟
الملخص (انسخ النص) + `build.log` إن فشل. وأخبرني هل ثُبّت الـ APK على هاتفك.

## ما اختُبر وما لم يُختبر
- **اختُبر محلياً (24 اختباراً):** حماية الاستخراج، اكتشاف المشروع (Java وKotlin مع Version Catalog وقديم)، قواعد الإصدارات، جمع الـ APK (لا يُعاد أي APK جاهز داخل الـ ZIP)، التشخيص، عزل بيئة البناء، المهلة، التنظيف، وعدم تعديل ملفات المشروع.
- **لم يُختبر:** بناء Gradle حقيقي (الاختبارات تستخدم Gradle محاكى). هذه التجربة هي أول اختبار حقيقي.
- جدول AGP←Gradle/JDK (`AGP_RULES`) يحتاج مطابقة مع ملاحظات إصدارات AGP الرسمية.

## قرارات التصميم والقيود
- لا يُشغَّل `gradle-wrapper.jar` ولا `distributionUrl` من المشروع؛ تُنزَّل توزيعة Gradle الرسمية وتُتحقق بـ sha256.
- لا تُعدَّل ملفات المشروع. يُبنى `assembleDebug` فقط (APK بتوقيع debug).
- بيئة البناء بلا أسرار، ومهلة 30 دقيقة.
- ليس عزلاً حقيقياً: Gradle ينفذ شيفرة المشروع. العزل بحاوية لكل بناء هو المرحلة 2 على خادمك.
- مكتبات المستودعات الخاصة أو المحذوفة ستفشل (يُشخَّص السبب).
