مشروع Android ← ملف APK

ارفع مشروعك (Java أو Kotlin) مضغوطاً بصيغة ZIP، واستلم ملف APK جاهزاً للتثبيت.

  • احذف مجلدَي build و.gradle قبل الضغط لتصغير الحجم.
  • لا تضع مفاتيح التوقيع (.jks) أو ملف local.properties داخل الـ ZIP.
